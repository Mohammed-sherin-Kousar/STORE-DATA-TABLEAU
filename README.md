# Store Data Analysis using Tableau

##  Project Overview

Developed an interactive **Store Data Analysis and Visualization project using Tableau** to analyze store performance and identify meaningful patterns in sales and business data. The project transforms store data into interactive visualizations and dashboards for easier business analysis.

##  Objective

* Analyze store sales and business performance.
* Identify important sales and performance patterns.
* Create meaningful data visualizations.
* Build an interactive Tableau dashboard.
* Present business insights through visual analysis.

##  Technologies Used

* Tableau
* Microsoft Excel
* Tableau Public
* Data Visualization
* Dashboard Development

##  Key Steps

* Imported and explored the store dataset.
* Connected the Excel data source to Tableau.
* Prepared and organized data for visualization.
* Created charts and visualizations using Tableau.
* Developed an interactive dashboard.
* Applied filters and interactive elements for dynamic analysis.
* Analyzed the resulting visualizations to identify business insights.

##  Analysis Performed

* Store performance analysis
* Sales analysis
* Category / product analysis
* Business performance trends
* Comparative analysis using Tableau visualizations
* Interactive dashboard exploration

##  Tableau Approach

* Connected Excel data to Tableau.
* Used **Dimensions and Measures** to create visualizations.
* Created multiple worksheets for individual analyses.
* Combined visualizations into an interactive dashboard.
* Used filters and dashboard interactions for dynamic exploration.
* Presented insights through visual storytelling.

## Result

* Successfully developed an interactive Tableau dashboard.
* Converted store data into meaningful visualizations.
